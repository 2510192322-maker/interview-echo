# 面试回声 · Interview Echo

回听一场面试，看清每一次回答。

一个面试复盘 Skill：把面试录屏、录音或转写稿整理为逐题记录，将**面试官提问、你的实际回答、AI 回答（标准答案视角）**分开，给老师留出批注空间。文首先放可查看回放和 ASR 原文的**通义听悟分析链接**，文末总结本场优势与可提升之处。

[English](README.en.md) · [技能说明](SKILL.md) · [虚构示例](examples/sample-review.md)

## 输出长什么样

```text
链接
  通义听悟分析页（对应录屏回放 + ASR 原文）

面试复盘
  Q1. 面试官实际问题
    我的回答：
    AI 回答（标准答案视角）：
      完整参考作答
      提示：原回答评价与具体改法
    老师建议：
      （此处留白，由老师填写）
  ……
  复盘小结（整体建议）
    优势：编号列出有依据的亮点
    可提升：编号列出问题及具体改法
```

## 特点

- **忠实记录回答**：去除口头重复，保留实际观点、错误、追问和未作答，不把 AI 优化答案混入原回答。
- **建议对应具体问题**：指出答得怎样、如何调整，并提供适合口头表达的参考回答。
- **听悟分析链接置顶**：打开同一分析页即可回看录屏并对照 ASR 原文；只有录音的场次使用含音频回放与原文的分析页。原始文件或单独附件不能替代分析链接。
- **尊重不确定性**：没有录到的问题、听不清的词、无法确认的说话人和缺失片段都明确标记。
- **老师独立批注**：每题留出老师建议区域，AI 不代填老师意见；文末由 AI 分优势与可提升作整体小结。
- **多场可分别复盘**：按场次区分音频和文档，必要时比较回答与指标口径的变化。

## 安装

将本仓库放进 Codex 的技能目录，目录名为 `interview-echo`。例如：

```bash
git clone https://github.com/2510192322-maker/interview-echo.git "${CODEX_HOME:-$HOME/.codex}/skills/interview-echo"
```

如果目标目录已存在，先检查现有内容，避免覆盖自己的修改。安装后在技能列表确认可以找到“面试回声 · Interview Echo”。其他支持 `SKILL.md` 的助手，可按照其技能导入方式加载本仓库。

## 使用

提供通义听悟分析页，或上传面试录屏、录音及转写稿，然后说：

```text
使用 $interview-echo 复盘这场面试。
文首放本场通义听悟分析链接，每题按 Q 问题、我的回答、
AI 回答（标准答案视角）、老师建议留白整理，文末写优势与可提升小结。
```

多场面试也可以一起处理：

```text
使用 $interview-echo 分别复盘这两场面试。
每份文首先放对应的听悟分析链接，逐题整理并分别给出整体小结。
```

## 运行条件与边界

这是给助手使用的工作流说明，不内置语音识别模型，也不是独立的视频处理应用。

- 使用视频或音频时，宿主需要能够理解音轨，或具有可用的语音转写工具。听悟链接应能打开本场回放和 ASR 原文；正文时间戳应匹配该版本。
- 缺少对应听悟分析页时，先检查既有记录或请求链接。只有转写稿时可以先做文字草稿，并标注“通义听悟分析链接待补”，不能伪造链接或声称全部交付完成。
- 默认输出 Markdown；Word、PDF 等导出取决于宿主已有的文档工具。
- 归档飞书等服务时，文首仍放听悟分析链接。原始音视频附件可作补充，但不能代替含 ASR 原文的分析页。保留已有老师批注。
- 默认交付入口为通义听悟。创建新的听悟分析记录需要已有用户授权；不能擅自付费或扩大分享权限。截图模板中的人物、经历和数字不能套用到候选人身上。
