# 面试回声 · Interview Echo

回听一场面试，看清每一次回答。

一个面试复盘 Skill：把面试录屏、录音或转写稿整理为逐题记录，将**面试官提问、你的实际回答、AI 建议**分开，给老师留出批注空间，并把音频链接放在最上面。

[English](README.en.md) · [技能说明](SKILL.md) · [虚构示例](examples/sample-review.md)

## 输出长什么样

```text
音频播放 / 下载链接（多场面试分别列出）

面试复盘
  第 1 题 · 主题与时间戳
    面试官问什么
    我答什么
    AI 建议
      回答评价
      怎么改
      参考回答
    老师建议（留白）
  ……
  老师总体建议（留白）
```

## 特点

- **忠实记录回答**：去除口头重复，保留实际观点、错误、追问和未作答，不把 AI 优化答案混入原回答。
- **建议对应具体问题**：指出答得怎样、如何调整，并提供适合口头表达的参考回答。
- **音频置顶**：从录屏导出完整音轨，或链接已有录音，方便老师边听边看；保留原始时间轴。
- **尊重不确定性**：没有录到的问题、听不清的词、无法确认的说话人和缺失片段都明确标记。
- **老师独立批注**：每题和文末留白，AI 不代填老师意见。
- **多场可分别复盘**：按场次区分音频和文档，必要时比较回答与指标口径的变化。

## 安装

将本仓库放进 Codex 的技能目录，目录名为 `interview-echo`。例如：

```bash
git clone https://github.com/2510192322-maker/interview-echo.git "${CODEX_HOME:-$HOME/.codex}/skills/interview-echo"
```

如果目标目录已存在，先检查现有内容，避免覆盖自己的修改。安装后在技能列表确认可以找到“面试回声 · Interview Echo”。其他支持 `SKILL.md` 的助手，可按照其技能导入方式加载本仓库。

## 使用

上传面试录屏、录音或转写稿，然后说：

```text
使用 $interview-echo 复盘这场面试。
最上面放音频链接，再逐题整理面试官的问题、我的实际回答和 AI 建议，
给每道题和文末留出老师建议的位置。
```

多场面试也可以一起处理：

```text
使用 $interview-echo 分别复盘这两场面试。
每份文首先放对应音频，另外总结需要优先改进的共同问题。
```

## 运行条件与边界

这是给助手使用的工作流说明，不内置语音识别模型，也不是独立的视频处理应用。

- 使用视频或音频时，宿主需要能够理解音轨，或具有可用的语音转写工具。
- 从视频导出音频需要相应音视频处理工具，例如 FFmpeg；只有转写稿时，仍可整理文字复盘，并注明未提供音频。
- 默认输出 Markdown；Word、PDF 等导出取决于宿主已有的文档工具。
- 本地音频路径只适合本机打开。如果要把复盘交给老师或放到飞书等服务，应按用户指定的目的地上传相应音频，替换为可访问的链接或附件；不要将本机路径当作云端共享链接。
- 本 Skill 不指定必须使用哪家转写服务。若需要向外部服务传送录音，应先确认用户授权了该去向。
